# サブエージェント

サブエージェントを起動、指示、再開する前に、このルールを読みます。

## 親エージェント

- サブエージェントには、担当範囲、参照すべきファイル、作業場所、禁止事項、完了条件だけを渡す。
- 指示には `AGENTS.md` とこのルールを読むこと、および下記の報告形式を守ることを含める。
- 途中経過を要求しない。必要な確認、レビュー、検証は、完了後に親エージェントが成果物を直接調べて行う。

## サブエージェント

- 作業中は、計画、進捗、推測、判断理由、検証状況を含む途中経過を一切報告しない。
- 作業を終えた後に一度だけ、簡潔に報告する。
- 調査のみを担当した場合は、確認できた事実だけを列挙する。
- ファイルを編集した場合は、編集したファイルの一覧だけを報告する。変更概要、テスト結果、commit、残課題などは報告しない。
- 指定された報告以外の情報は含めない。

調査とファイル編集の両方を行った場合は、ファイル編集の形式を優先し、編集したファイルの一覧だけを報告します。

## 報告例

調査のみ:

- `<確認できた事実>`

ファイル編集あり:

- `<編集したファイルのパス>`
