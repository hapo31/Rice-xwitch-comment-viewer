# Twitch 認証情報の保存と安全性

Twitch の access token と refresh token は OS の資格情報ストアへ保存します。設定 JSON や平文ファイルへ新たに保存することはありません。

OS の資格情報ストアを利用できない場合でもログインは継続できますが、その認証は今回の起動中だけ有効です。アプリを終了または再起動した後は、もう一度 Twitch にログインしてください。

旧版を Linux で利用していた場合、`~/.rice/twitch-auth.json` が残っていることがあります。資格情報ストアが利用できる場合は自動的に移行して削除します。移行できない場合、アプリは安全のためそのファイルを読み込みません。次の手順で対応してください。

1. `~/.rice/twitch-auth.json` を削除する。
2. Twitch の「設定と接続」から、このアプリのアクセスを取り消す。
3. アプリで Twitch に再ログインする。

Twitch 連携を解除すると、OS の資格情報ストアと旧ファイルの両方を削除します。削除に失敗した場合は警告を確認し、資格情報ストアを利用可能にしてから再度解除してください。
